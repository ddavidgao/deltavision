# Angl safety migration

This branch migrates one production-relevant DeltaVision boundary to Angl without
rewriting the app.

## What changed

`SafetyLayer.check_action` still exposes the same Python API. The safety policy
decision now lives in an Angl chapter:

```text
specs/evaluate_action_safety.angl
```

The generated runtime artifact is:

```text
angl_build/safety/evaluate_action_safety.js
```

The Python adapter generated by Angl is:

```text
angl_build/safety/evaluate_action_safety.py
```

## Why this is useful

This is the migration path Angl should support:

1. Pick one function boundary.
2. Write the intended behavior and contract cases in `.angl`.
3. Compile it into a disposable artifact.
4. Keep the existing application API stable.
5. Run the existing app tests plus the Angl judge.

The rest of DeltaVision remains ordinary Python. Only the safety decision
boundary moved.

## Rebuild

From the repo root:

```bash
ANGL_MODEL_PROVIDER=claude-code ANGL_MODEL=sonnet uv run python scripts/compile_angl_safety.py
```

The compiler writes generated output into `angl_build/safety/`.

## Validation

This migration was validated with:

```bash
uv run --extra dev pytest tests -q
uv run --extra dev ruff check safety.py scripts/compile_angl_safety.py
```

Observed result:

```text
292 passed, 2 skipped
All checks passed
```
